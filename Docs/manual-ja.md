# かいへんナビ 説明書

VRChat のアバター改変を始めた方のための説明書です。
かいへんナビ 0.1.0 の日本語画面に合わせています。
画面にある言葉は「かぎ括弧」で書きます。

## 1. かいへんナビでできること

かいへんナビは、Unity の中で使う改変ツールです。
「服を着せたい」など、やりたいことから操作を選べます。
まず①でアバターを選びます。
次に②でカードを押します。
③「調整する」に、選んだカードの操作が出ます。

<!-- 画像: ①アバターをえらぶ・②やりたいことをえらぶ・③調整するが見える画面全体 -->

### 体験版と製品版の違い

カードは、次の順番で並びます。
製品版では、体験版の機能も使えます。

| カードの名前 | 体験版 | 製品版 |
| --- | --- | --- |
| 服を着せたい | 使えます | 使えます |
| アクセをつけたい | 使えます | 使えます |
| 髪や服の色を変えたい | 使えます | 使えます |
| 服やアクセを脱ぎ着できるようにしたい | 使えます | 使えます |
| 体型・身長を変えたい | ― | 使えます |
| 動きを変えたい | ― | 使えます |
| メニューを整理したい | ― | 使えます |
| 服からはみ出る肌を隠したい | ― | 使えます |
| 視点の高さを直したい | ― | 使えます |
| ピンク色を直したい | ― | 使えます |
| 明るさや影を整えたい | ― | 使えます |
| きれいなサムネイルにしたい | ― | 使えます |

体験版では、使えないカードに「製品版」と表示されます。
アバターの新規作成、続きの改変、自動保存、バックアップは体験版でも使えます。
アップロード先の表示と、アップロード前のチェックも使えます。
「別バージョンを作る」と、一覧での名前の変更は製品版の機能です。

### 元のアバターとの関係

買ったアバターをもとに、改変用のアバターを別に作ります。
色を変えるときも、見た目の設定をコピーしてから変えます。
買ったアバターの形や色のファイルを、直接書き換えることはありません。

ただし、アップロード前のチェックの「直す」は例外です。
配布されたモデルの読み込み設定を変えます。
実行前に確認画面が出ます。詳しくは6章で説明します。

## 2. 入れる前の準備・入れ方・開き方

### 必要なもの

| 用意するもの | 説明 |
| --- | --- |
| VCC または ALCOM | VRChat 用の制作環境を管理するアプリです。アバター用の Unity プロジェクトを用意します。 |
| Unity 2022.3 系 | プロジェクトを開いて改変するアプリです。動作確認には 2022.3.22f1 を使っています。 |
| VRChat SDK Avatars 3.5.0 以降 | アバターを VRChat に送るための道具です。 |
| 改変したいアバター | アバターの説明書に従って、先にプロジェクトへ入れてください。 |
| アバターや服が必要とするシェーダー | 色や影の描き方を決める道具です。必要なものは、各商品の説明書で確認します。 |

Modular Avatar は、追加の改変をまとめて組み込む無料ツールです。
かいへんナビ自体を開くためには必須ではありません。
ただし、服を着せる、脱ぎ着メニューを作る、体型を変える、動きを変える、メニューを整理する機能で使います。
服を着ているときだけ肌を隠す機能でも使います。
VCC または ALCOM で、プロジェクトに追加してください。
README の対応目安は 1.10.0 以降です。
動作確認には 1.18.7 を使っています。
「Mesh Cutterで切り取る（上級）」は、Mesh Cutter が含まれる版が必要です。

lilToon は、シェーダーの一種です。
色変えでは、対応する色の調整を使えます。
「明るさや影を整えたい」は lilToon 専用です。
それ以外のシェーダーを使うアバターに、必ず入れる必要はありません。

### 入れ方

この版で README に記載されている方法は、フォルダのコピーです。
VPM と unitypackage での配布は準備中です。

1. VCC または ALCOM で、アバター用のプロジェクトを用意します。
2. アバターの説明書に従い、必要なシェーダーとアバターを入れます。
3. 使う機能に合わせて、Modular Avatar を追加します。
4. 配布フォルダ内の `Packages/com.suzuki-y0.jeni.kaihen-navi` をコピーします。
5. コピー先は、使うプロジェクトの `Packages` フォルダです。
6. Unity でプロジェクトを開き、読み込みが終わるまで待ちます。

コピー後は、`Packages/com.suzuki-y0.jeni.kaihen-navi/package.json` がある形になります。
`Assets` フォルダの中に入れる手順ではありません。

### 開き方

Unity の上のメニューから **Tools > かいへんナビ** を押します。

## 3. 最初にやること：①アバターをえらぶ

### 新しく始めるとき

1. 「新しく改変アバターを作る」を押します。
2. 「もとにするアバターをえらんでください」の一覧で、使うアバターを押します。
3. 「改変アバターの名前」に、分かりやすい名前を入れます。
4. 「保存先」を確認し、「改変アバターを作る」を押します。
5. 作成できたことを知らせる画面で「OK」を押します。

作ったアバターだけが、シーン（アバターを置いて見る作業画面）に表示されます。
ほかのアバターは隠れます。
元のファイルが消えるわけではありません。

<!-- 画像: 新規作成画面の元アバター一覧・名前・保存先・「改変アバターを作る」 -->

### 「改変のベース」は、みんな共通の土台です

初めて作るときは、「改変のベース」も自動で作ります。
つながりは「買ったアバター → 改変のベース → 自分の改変アバター」です。
同じ元アバターから作るものは、同じ土台を使います。

たとえば、製品版の「動きを変えたい」で、同じ土台を使うみんなの歩き方をまとめて変えられます。
1体だけ違う動きにもできます。
その場合は、その1体で選んだ動きが優先されます。
最初は、ベースのファイルを自分で操作する必要はありません。

### 続きから直すとき

1. 「前に作った改変アバターを直す」を押します。
2. 一覧から直したいアバターを探します。
3. その行の「これを直す」を押します。

改変中に切り替えるときは、「ほかのアバターにする」を押します。
「場所」を押すと、Unity の Project（ファイルの一覧）で保存ファイルを示します。

製品版では「別バージョンを作る」で、衣装違いなどのコピーを作れます。
コピーは、一覧の「これを直す」から開きます。
コピーのアップロード先は、新しいアバター用になります。
名前は、一覧の名前欄を書き換えて、欄の外を押すと変更できます。
保存ファイルとフォルダの名前も変わります。

「ベースにつなぎ直す」が出るのは、共通の土台を通らずに作られたものです。
みんな共通の設定を使う場合に押します。
確認画面の内容を読み、実行後は見た目を確かめてください。
つなぎ直す前のファイルは、そのアバターの `Backups` にコピーされます。

### すでにシーンで改変していたとき

「シーンにあるアバター」の「これを直す」から開けます。
「改変アバターにする」の案内が出たら、そのボタンを押してください。
今の改変を残して、自動保存できる形にします。
元とのつながりが切れている場合は、「今の状態を改変アバターとして保存」が出ます。

「あとで」を選ぶと、改変はシーンの中にだけ残ります。
この場合は、Unity でシーンを保存してください。
かいへんナビの自動保存が使える状態とは異なります。

## 4. ②のカードごとの使い方

②「やりたいことをえらぶ」でカードを押します。
操作は③「調整する」に出ます。
「更新」を押すと、操作欄の一覧を読み直せます。

### 服を着せたい（体験版・製品版）

このアバター用に作られた服を着せます。
別のアバター用の服を、自動で作り直す機能ではありません。
Modular Avatar が必要です。

1. 「着せる服をえらぶ」で、服の Prefab（青い箱のアイコンの、ひとまとまりのデータ）を選びます。
2. Project から案内の枠へドラッグできます。
3. ドラッグが難しいときは、「または一覧から選ぶ」で選び、「これにする」を押します。

「このアバター用らしい服（押すと着せます）」の候補は、押すと着せます。
候補が対応しているかは、服の商品説明でも確認してください。
「持っているアイテムから探す」では、「名前で探す」に商品名などを入れて探せます。
候補の一覧を押すと着せます。
見つからないときは「今入っているアイテムを読み込む」か「読み込み直す」を押します。
探せるのは、このプロジェクトに入っているものです。

着せた服は「着ている服」に出ます。
「脱がす」で隠し、「着せる」で再び表示できます。
服を着せる操作自体を取り消すときは、画面下の「元に戻す」を使います。
元から着ている服と重なるときは、「脱ぎ着の設定へ」から切り替えを設定します。

<!-- 画像: 服を選ぶ枠・「または一覧から選ぶ」・「これにする」・「着ている服」 -->

### アクセをつけたい（体験版・製品版）

1. 「つけるアクセをえらぶ」で、アクセの Prefab をドラッグします。
2. 「または一覧から選ぶ」で選び、「これにする」を押しても選べます。
3. 「どこにつけますか？」で、「頭・顔・耳」や「右手首」などを選びます。
4. 「アクセをつける」を押します。

候補や「持っているアイテムから探す」からも選べます。
選び直すときは「えらび直す」を押します。

つけると、同じページで位置・向き・大きさの調整欄が開きます。
最初の位置は目安なので、見た目を見ながら合わせてください。

- 「位置」の上下・前後・左右スライダーを動かします。単位は cm です。
- 位置と向きは、つけた骨を基準にしています。骨によって軸の向きが違うことがあります。
- 「向き」の X・Y・Z 軸スライダーで回したり傾けたりします。
- 「大きさ（%）」で、全体を同じ割合で大きくしたり小さくしたりします。
- 数値は直接入力もできます。
- 「シーンで動かす」で対象に寄り、Unity の移動ツールでも動かせます。

「推定した位置に戻す」で、装着直後の位置・向き・大きさに戻せます。
「完了」で調整欄を閉じます。
後から直すときは「つけたアクセ」一覧の「調整」、外すときはその行の「外す」を押します。
装着・取り外し・調整は、Ctrl+Z でひとつ前に戻せます。
このツールでつける前からあるアクセでは、最初に調整欄を開いた位置が戻す基準になります。
シーンで対象をクリックし、「シーンでえらんだものを使う」から調整する方法もあります。

<!-- 画像: アクセをつける場所の選択と、位置・向き・大きさの操作 -->

### 髪や服の色を変えたい（体験版・製品版）

1. 「どこの色を変えますか？」で「髪」「服」「目」「肌」「その他」を選びます。
2. 一覧で、変えたい行にチェックを入れます。
3. 「色味」「鮮やかさ」「明るさ」のつまみを動かします。

変えたくない行は、チェックを外します。
場所の判定が違うときは、一覧の右側で場所を選び直します。
たとえば、目の設定が「肌」に入っている場合もあります。
行をダブルクリックすると、シーン内の場所を示します。

「最初の色に戻す」で、チェックした色を戻せます。
lilToon の色調補正は、色味0・鮮やかさ100・明るさ100になります。
商品の作者が調整した値と同じになるとは限りません。
lilToon 以外では、この操作中に覚えた色へ戻します。
変更前の状態を確実に選びたいときは、「元に戻す」か「履歴」を使ってください。

lilToon 以外では、全体の色合いだけを変えます。
同じ見た目の設定を使う場所は、一緒に色が変わることがあります。

<!-- 画像: 色変えの場所・チェック・3本のスライダー・「最初の色に戻す」 -->

### 服やアクセを脱ぎ着できるようにしたい（体験版・製品版）

VRChat の中で、服やアクセを表示したり隠したりするメニューを作ります。
メニュー作成には Modular Avatar が必要です。

1. 「メニューに入れるもの（名前はメニューに表示されます）」で、対象にチェックを入れます。
2. 必要なら、行の名前を書き換えます。
3. 「脱ぎ着の切り替えを作る」を押します。

髪や体などは「そのほか（髪・体など）」を開くと出ます。
作成済みの行には「メニューに追加済み」と表示されます。
選ぶものや名前を変えた後は、「脱ぎ着の切り替えを作り直す」を押します。

アップロードすると、VRChat の「脱ぎ着」メニューから使えます。
作る前に表示されていたものはオン、非表示だったものはオフで始まります。
服やアクセ本体の表示状態を、メニュー作成のために非表示にすることはありません。
「通信量」が上限を超えそうなときは、チェックする数を減らします。
この表示には、ほかのツールが追加する分は含まれません。

作った切り替えを外すときは「脱ぎ着の切り替えを消す（元に戻す）」を押します。
服やアクセの表示は、最初に切り替えを作る前の状態へ戻ります。
作成・作り直し・削除は、それぞれ Ctrl+Z 1回で戻せます。
まとまった変更を戻すときは、画面下の「元に戻す」や「履歴」も使えます。

Modular Avatar がない場合は、「いまの見た目だけ切り替える」が出ます。
そこで選んだ表示状態でアップロードされます。
VRChat の中で切り替えるメニューは作られません。

<!-- 画像: 脱ぎ着の一覧・折りたたみ・通信量・作成と削除のボタン -->

### 体型・身長を変えたい（製品版）

人型として設定されたアバターが対象です。
Modular Avatar が必要です。

1. 影絵の点か、横の部位のボタンを押します。
2. 「長さ（%）」「太さ（%）」のつまみを少しずつ動かします。
3. 頭・手・足では「大きさ（%）」を変えます。
4. 身長は「全身（身長）」を選び、「身長（%）」を変えます。

点をつかんで動かす方法もあります。
上下で長さ、左右で太さを変えられます。
左右の部位は一緒に変わります。
腰の点を上下に動かすと、身長を変えられます。

頭・手・足は、ついている髪や指、靴、アクセなども一緒に大きくなります。
身長を変えると、視点も自動で合わせます。
表示される身長は目安です。アクセの先まで含むことがあります。
見た目への反映に少し時間がかかる場合があります。

「この部位をもとに戻す」で、選んだ部位を戻します。
「全部もとに戻す」で、体型と身長をまとめて戻します。
途中の状態へ戻したいときは「履歴」を使います。
アップロード後は、VRChat の中でも立ち姿や歩く動きを確かめてください。

<!-- 画像: 体型の影絵と部位の点・「全身（身長）」・戻すボタン -->

### 動きを変えたい（製品版）

Modular Avatar が必要です。

1. 「どの動きを変えますか？」で「歩き方」「座り方」「エモート・AFK」を選びます。
2. 「どのアバターの動きを変えますか？」で、変更する範囲を選びます。
3. 「動きをえらぶ」の枠へ、動きのファイルをドラッグします。

使えるのは、動きをまとめた `.controller` ファイルか、対応する Modular Avatar 用の Prefab です。
`.controller` は「または一覧から選ぶ」で選び、「これにする」でも使えます。
手の形や、表情の仕組みを入れ替えるカードではありません。

まずは「このアバターだけ」を選ぶと、変更の範囲を確かめやすくなります。
「同じアバターから作ったみんな」では、共通のベースを変えます。
確認画面に出る対象を読んでから進めてください。
1体だけ別の動きにしている場合は、そちらが優先されます。

戻すときは、同じ動きの種類と範囲を選び、「元の動きに戻す」を押します。
特に「同じアバターから作ったみんな」の変更は、Ctrl+Z では戻せません。
「元の動きに戻す」を使ってください。
重なりの警告が出たら、そのアバターを開き、「重なりを直す（このアバターで入れた方を使う）」を押します。

動きの入れ替えは、アップロード時に組み込まれます。
Unity の再生ボタンや、別途導入した Gesture Manager でも確かめられます。

<!-- 画像: 動きの種類・「このアバターだけ」と「同じアバターから作ったみんな」 -->

### メニューを整理したい（製品版）

アバターに最初から入っている、VRChat 内の操作メニューを整理します。
Modular Avatar が必要です。

1. 「メニューを整理できるようにする」を押します。
2. 出てきた一覧で、使わない項目のチェックを外します。
3. 「↑」「↓」で順番を変えます。
4. 名前欄を書き換え、欄の外を押すと、表示名を変えられます。
5. 「その他へ」で、あまり使わない項目をまとめられます。

「その他」に移した項目は、「上に戻す」で戻せます。
チェックを外した項目は「使わない項目」に出ます。
再びチェックすると、使う項目に戻ります。

チェックを外すと、操作のボタンが消えます。
服や機能そのものが消えるわけではありません。
「オンのまま固定」「オフのまま固定」など、行の説明を確認してください。
通信量も、それだけでは減りません。
元から入っているメニューが対象なので、別のツールが足す項目をすべて整理できるわけではありません。

整理を全部やめるときは、「元のメニューに戻す」を押します。
途中まで戻すときは、画面下の「元に戻す」や「履歴」を使います。
チェックや順番の変更は、Ctrl+Z で戻せない場合があります。

<!-- 画像: メニュー整理の一覧・矢印・「その他へ」・使わない項目の固定状態 -->

### 服からはみ出る肌を隠したい（製品版）

服の外へ出てしまう肌を、縮めたり切り取ったりします。
服そのものの形を直す機能ではありません。

1. 「シェイプキーで縮める（おすすめ）」を選びます。
2. 肌の候補が複数ある場合は、「どこの肌ですか？（数字は縮める用のシェイプキーの数）」で体を選びます。
3. 「いつ隠しますか？」で「いつも隠す」か、「『服の名前』を着ているときだけ」を選びます。
4. 「縮める所」を調整します。

シェイプキーは、アバターに用意されている形の調整です。
「いつも隠す」では、つまみを動かし、はみ出しが消える所で止めます。
服を選んだ場合は、縮めたい所にチェックを入れます。
その服を着ているときだけ縮み、脱ぐと戻ります。
この切り替えには Modular Avatar が必要です。

候補がないときは「そのほかのシェイプキーも出す」で探せます。
戻すときは、服用のチェックを外すか、変更前の値へ戻します。
値が分からないときは「元に戻す」や「履歴」を使います。

「Mesh Cutterで切り取る（上級）」も選べます。
「Mesh Cutterを置く」を押した後、Inspector（選んだものの詳しい設定欄）で切り取る範囲を決めます。
肌の対象は自動で入りますが、範囲は自分で決める必要があります。
元の体のファイルを切るのではなく、アップロード時に切り取りを組み込みます。
置く操作は「元に戻す」で取り消せます。
Mesh Cutter がないという案内が出たら、Modular Avatar を更新してください。

### 視点の高さを直したい（製品版）

VRChat で自分が見る位置を調整します。

1. 「目の位置に自動で合わせる」を押します。
2. 「シーンで見る」を押して、ピンクの玉を確認します。
3. 「少しずつ直す」の上下・前後の矢印で調整します。

目と目のあいだで、顔の表面より少し前が目安です。
自動で合わせられないという案内が出たら、矢印で合わせます。
調整前へ戻すときは「元に戻す」を使います。

<!-- 画像: 視点カードと、顔の前に表示されたピンクの玉 -->

### ピンク色を直したい（製品版）

ピンク色の原因になりそうな見た目の設定を調べ、直し方を案内します。
必要な道具を自動で入れる機能ではありません。

1. 表示された原因と、対象の名前を読みます。
2. たとえば「lilToon の入手先を開く」が出たら、そこから入手先を開けます。
3. 案内とアバターの説明書に従い、必要なシェーダーなどを入れます。
4. 「もう一度調べる」を押します。

「場所」で、対象の見た目の設定や物を示せます。
見分けられない場合は、アバターの説明書にある必要なものを確認します。
「素材（マテリアル）が外れている所」が出る場合もあります。
マテリアルは、色や質感をまとめた設定です。
この場合は、案内に従い、Inspector の「Materials」に元の設定を入れます。

このカードは診断と案内です。
シェーダーの導入や、Inspector で行った修正は、かいへんナビの「元に戻す」の対象ではありません。

### 明るさや影を整えたい（製品版）

lilToon の見た目の設定を調整します。

1. 「どれを整えますか？」で「ぜんぶ」か、服や髪などを選びます。
2. 変えたい行だけにチェックを入れます。
3. 「おすすめから選ぶ」のボタンを押します。

おすすめは「暗い場所でも見やすく」「影をやわらかく」「まぶしくならないように」です。
「細かく調整する」では、暗いときや明るいときの限度、影の濃さなどを変えられます。
まずは少しずつ動かしてください。

「lilToon の標準に戻す」は、このカードの項目を lilToon の標準値にします。
アバターを買ったときの見た目へ戻すボタンではありません。
変更前へ戻すときは、「元に戻す」や「履歴」を使います。
影がオフという案内がある場合は、影の項目を変えても、その設定には影が出ません。
同じ設定を使う複数の場所が、一緒に変わる場合もあります。

### きれいなサムネイルにしたい（製品版）

VRChat のアバター一覧に使う画像を撮ります。

1. 「写す範囲」で「顔アップ」「上半身」「全身」を選びます。
2. 「向き」で「正面」「左ななめ」「右ななめ」を選びます。
3. 「背景」と「大きさ（%）」を調整します。
4. 写りを見て、「この画像を保存」を押します。

背景は「シーンのまま」「白」「ピンク」「水色」「暗い色」から選べます。
画像は、アバターのフォルダの `Thumbnail.png` に保存されます。
大きさは 1200 × 900 ピクセルです。
保存し直すと、同じファイルを上書きします。
この画像の上書きは、「元に戻す」では取り消せません。
前の画像も残したい場合は、保存し直す前に別の場所へコピーしてください。
撮影では、アバターの形や色は変わりません。

## 5. 元に戻す・履歴・保存

### 「元に戻す」と「履歴」

画面下の「元に戻す」で、直近のバックアップへ戻せます。
確認画面に出る時刻と、「何の前」の状態かを読んでから「戻す」を押します。
もっと前へ戻すときは、「履歴」から選びます。

バックアップは、カードを選んで最初に何かを変える直前に作られます。
同じカードを続けて操作している間は、操作ごとには増えません。
アバターごとに最大20件です。
上限を超えると、古いものから消えます。

履歴から戻すと、選んだバックアップと、それより新しいバックアップは消えます。
その間にツールでつけた服やアクセも、戻す対象になります。
戻す前の状態へ戻したいときは、直後に Ctrl+Z を使えます。
ただし、消えたバックアップの一覧が復活するわけではありません。

細かな操作は Ctrl+Z でも取り消せます。
スライダーを続けて動かした分は、まとめて戻る場合があります。
メニューの並べ替えなどは、かいへんナビの「元に戻す」を使ってください。
共通の動き、モデルの読み込み設定、サムネイル画像には、それぞれ4章・6章に書いた戻し方の制限があります。

<!-- 画像: 画面下の「自動バックアップ」件数・「履歴」・「元に戻す」と履歴の一覧 -->

### 自動保存と「今すぐ保存」

改変アバターでは、かいへんナビを開いている間、操作が止まって約1.5秒後に変更を保存します。
保存先は、①で選んだ改変アバターです。
買った元のアバターへ保存する操作ではありません。

作業を区切るときは、保存の案内の横にある「今すぐ保存」を押せます。
保存が行われると、案内に保存時刻が出ます。
「場所」で保存先を確認できます。
自動保存は今の改変を残す仕組みです。
バックアップは前の状態へ戻すための仕組みです。
「今すぐ保存」を押しても、履歴が1件増えるわけではありません。

シーンの保存は、Unity の File > Save で行います。
まだ改変アバターにしていない場合は、特に保存を忘れないでください。

## 6. アップロードの前に

### モデルの読み込み設定を確認する

①の下に「アップロードの前に直す必要があるモデルが…」という案内が出ることがあります。
対象のファイルと「Read/Write がオフ」「シェイプキーの法線の設定」などが表示されます。
これは、モデルを Unity に読み込むときの設定です。

1. 表示されたファイルと内容を確認します。
2. 「直す」があれば押します。
3. 確認画面を読み、変更してよければ「直す」を押します。

モデルの形や色は変わりません。
VRChat SDK の「Auto Fix」と同じ種類の変更です。
ただし、配布されたファイルの設定を記録する `.meta` を変えます。
同じモデルを使う、ほかのアバターにも関係します。
**この変更は、かいへんナビの「元に戻す」では戻せません。**

「確認できませんでした」と出たモデルは、自動では直しません。
表示された場所の元ファイルの設定を確認してください。
このチェックは、一部の読み込み設定が対象です。
警告がなくても、VRChat SDK 側のチェックは必要です。

<!-- 画像: アップロード前の警告・モデル名と場所・「直す」の確認画面 -->

### アップロード先を確認する

改変アバターを選ぶと、①にアップロード先が表示されます。

| 表示 | 次にアップロードするとき |
| --- | --- |
| アップロード先：まだアップロードしていません（新しいアバターとして出ます） | 新しいアバターとして追加します。 |
| アップロード先：…（前にアップロードしたアバターを更新します） | 表示された ID のアバターを更新します。 |

新規作成や「別バージョンを作る」では、元のアップロード先を引き継ぎません。
前のアバターを残して新しく追加したいときは、「新しいアバターとして出す」を押します。
確認後は、前のアップロード先とのつながりを外します。
すでに VRChat にあるアバターは消えません。

別の改変アバターと同じアップロード先だという警告が出たら、先に確認してください。
どちらかを「新しいアバターとして出す」にすると、上書きを避けられます。
アップロード先の ID は、アバターの送り先を識別する番号です。
見た目のバックアップで、この番号まで戻せるわけではありません。

<!-- 画像: アップロード先の表示・「新しいアバターとして出す」・同じ送り先の警告 -->

### サムネイルを選び、SDK からアップロードする

かいへんナビに、アバターをアップロードするボタンはありません。
アップロードは VRChat SDK の画面で行います。
製品版で撮った画像を使う場合は、SDK のアップロード画面で `Thumbnail.png` を選びます。
画像を保存しただけでは、自動でアップロード用画像にはなりません。

アップロード前に、服の重なり、肌のはみ出し、視点、動きも確かめてください。
SDK の案内を確認し、アップロード後は VRChat の中でも見た目と動作を確認します。

## 7. 困ったとき

### アバターが一覧に出ません

アバターのデータを、先にプロジェクトへ入れてください。
新規作成の一覧には、アバターとして設定された Prefab が必要です。
前に作ったものは、「前に作った改変アバターを直す」で探します。
シーンにだけ置いていたものは、最初の画面の「シーンにあるアバター」で探します。

### 服やアクセが候補に出ません

まず、その商品をプロジェクトへ入れてください。
「持っているアイテムから探す」で名前を変えて探すか、一覧を読み込み直します。
候補に出なくても、Project からドラッグしたり、「または一覧から選ぶ」で指定したりできます。
つけた後の調整対象が出ないときは、「更新」か、カードの選び直しを試してください。

### アバターや服がピンク色です

必要なシェーダーが入っていない可能性があります。
製品版では「ピンク色を直したい」の案内を読みます。
体験版でも、アバターや服の説明書で必要なシェーダーを確認できます。
ロックの設定や、PC 用・Android 用の違いが原因の場合もあります。
ツールが原因をすべて見分けられるわけではありません。

### メニューが多すぎます

製品版の「メニューを整理したい」で、順番や名前を変えられます。
あまり使わないものは「その他へ」でまとめます。
チェックを外すとボタンは消えますが、機能は表示された状態で固定されます。
メニューを隠すだけで、通信量の問題がすべて解消するわけではありません。

### 服が体に合いません

その服が、このアバター用かを確認します。
「服を着せたい」は、体の動きに合わせる設定を行います。
別の体型に合わせて服の形を作り直すことはできません。
着せる操作をやめるときは「元に戻す」を使います。
元の服と重なっているだけなら、脱ぎ着カードで表示を切り替えます。
肌が少し出る場合は、製品版の「服からはみ出る肌を隠したい」を使えます。

### 位置のスライダーを動かしても、服が動きません

体に合わせて形が変わる服は、位置の変更が見た目に出ない場合があります。
アクセの位置調整で、服のサイズ合わせをすることはできません。
「最初の位置に戻す」か「元に戻す」で取り消してください。

### 脱ぎ着メニューが作れません

Modular Avatar が必要です。
VCC または ALCOM で追加した後、もう一度カードを開きます。
追加する物にチェックがあるかも確認してください。
通信量の警告が出た場合は、メニューに入れる数を減らします。

### 色や明るさを変えたい場所が見つかりません

色の場所は自動で判定しています。
「髪」などにない場合は、「肌」や「その他」も探します。
一覧の右側で場所の振り分けを変えられます。
「明るさや影を整えたい」は lilToon 専用です。
色変えも、色を調整できる設定があるものだけが対象です。

### ほかのアバターが見えなくなりました

かいへんナビは、選んだアバターを見やすくするために、ほかのアバターを隠します。
「ほかのアバターにする」から、使いたいものを選び直してください。

### 保存されているか心配です

「改変アバター」になっているかを①で確認します。
「今すぐ保存」を押し、保存先は「場所」で確認します。
「まだ改変アバターになっていません」と出ていたら、「改変アバターにする」を押してください。
シーンにだけ残す場合は、Unity でシーンを保存します。

## 8. ツールが作るフォルダ

データは、プロジェクト内の `Assets/KaihenNavi` に置きます。
改変アバター1体につき、専用のフォルダを使います。
`<元アバター名>` と `<改変アバター名>` の部分には、実際の名前が入ります。

```text
Assets/KaihenNavi/
  README.md
  Ledger/
    items.json
  Bases/<元アバター名>/
    <元アバター名> Base.prefab
    avatar.json
  Avatars/<改変アバター名>/
    <改変アバター名>.prefab
    avatar.json
    Materials/
    Textures/
    Menus/
    Backups/
    Thumbnail.png
```

| 名前 | 入っているもの |
| --- | --- |
| README.md | このフォルダの使い方の説明です。 |
| Ledger/items.json | 取り込んだ商品と、ファイルの場所の記録です。 |
| Bases | 同じ元アバターから作る、みんな共通の土台です。共通の動きなどを持ちます。 |
| Bases 内の avatar.json | このデータがベースであることなどを記録します。 |
| Avatars | 改変したアバターを、それぞれの名前で保存します。 |
| 名前が付いた .prefab | 改変アバター本体のデータです。共通のベースにつながっています。 |
| Avatars 内の avatar.json | 元アバターや作成日時などの記録です。ほかのツールも読める形になっています。 |
| Materials | 色や明るさを変えるためにコピーした、見た目の設定です。 |
| Textures | 作った画像などを置きます。必要になったときだけ作られます。 |
| Menus | メニュー整理で使う、空の元メニューを置きます。必要になったときだけ作られます。 |
| Backups | 自動バックアップです。ベースにつなぎ直す前のコピーが入る場合もあります。 |
| Thumbnail.png | 保存したアップロード用の画像です。撮影して保存したときにできます。 |

必要なときに作るため、最初から全部のファイルやフォルダがあるとは限りません。
色などを戻しても、コピーした見た目の設定がフォルダに残ることがあります。
買った元アバターのファイルは、別の場所にそのまま残ります。
これらの保存データは、かいへんナビが続きの改変や復元に使います。
