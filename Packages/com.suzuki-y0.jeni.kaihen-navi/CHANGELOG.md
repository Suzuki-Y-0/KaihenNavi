# 更新履歴

## 0.1.0（開発中）

- アクセの装着・取り外しと、脱ぎ着の作成・作り直し・削除を、Prefab 保存も含めて1回の Ctrl+Z で戻すよう修正（Unity 実機は未確認）
- アクセに「つけたアクセ」一覧と、装着直後の位置（cm）・3軸回転・大きさのスライダー、推定位置への復帰、Scene の移動ツールへの案内を追加
- 脱ぎ着の作成で服本体を非表示にせず、削除時には記録した元の表示へ戻すよう変更

- 初版。体験版の 3 機能を実装。
  - 髪や服の色を変えたい（lilToon は色調補正、それ以外はメインカラー）
  - 服やアクセを脱ぎ着できるようにしたい（Modular Avatar があればメニューを自動生成）
  - アクセの位置や大きさを直したい（矢印ボタンとスライダー）
- 操作ごとの自動バックアップと「元に戻す」「履歴」
- 日本語・英語・中国語（簡体字）・韓国語に対応
- ①を「新しく改変アバターを作る／前に作った改変アバターを直す」の二択に（未確認）
  - 新しく作ると、元アバターのプレハブバリアントと決まった形のフォルダ（Assets/KaihenNavi/Avatars/名前/）を自動で作る
  - 改変は改変アバターに自動で保存（元の Prefab には書き込まない）
  - 製品版: 別バージョンを作る、名前を変える
- 「服を着せたい」を追加（服をえらぶだけで Modular Avatar で着せる）（未確認）
- 「アクセの位置や大きさを直したい」を「アクセをつけたい」に作り替え（付ける場所をえらんで付け、そのまま微調整）（未確認）
- 製品版の機能を追加（未確認）
  - 体型・身長を変えたい（影絵とボーン図の点をつまんで長さ・太さを変える。身長を変えると視点も自動で合わせる）
  - 視点の高さを直したい（目の位置に自動で合わせ、矢印で微調整）
  - ピンク色を直したい（足りないシェーダーを見分けて入手先を案内）
  - きれいなサムネイルにしたい（顔がゆがまない画角で撮って保存）
  - 服からはみ出る肌を隠したい（シュリンクのシェイプキーを縮める。服を選ぶとその服を着ているときだけ。Mesh Cutter も案内）
  - メニューを整理したい（元のメニューを MA のメニュー項目として取り出し、使う／使わない・並べ替え・名前の変更・「その他」にまとめる。元のメニューのファイルは変えない）
  - 動きを変えたい（歩き方・座り方・エモート/AFK。MA Merge Animator の置き換えで非破壊。「このアバターだけ」か「同じアバターから作ったみんな」を選べる）
  - 明るさや影を整えたい（lilToon の明るさ・影の項目だけを、アイテムごとにおすすめとスライダーで変える。マテリアルは自動で複製）
- 改変アバターを「元アバター → 改変のベース → 改変アバター」の 2 段で作るように変更（歩き方など共通の設定をベースで変えれば全員に効く。今までの改変アバターも「ベースにつなぎ直す」で同じ形にできる）（未確認）
- アップロード先の表示と、上書き事故の防止（新しく作った改変アバターはブループリント ID を外す）（未確認）
- Unity 2022.3.22f1 の実機で確認して修正（10-19）
  - 本文がスクロールしない不具合を修正（体型機能の部品名が本文と重なっていた）
  - 服: Modular Avatar の Setup Outfit が「オブジェクトが選択されていません」になる不具合を修正
  - 肌: 顔ではなく体のメッシュを選ぶように（選び直しもできる）。Mesh Cutter は切り取る相手を最初から入れる
  - 身長を実際の形から測るように（大きめに出ていた）。着せた服は除き、身長を変えたら表示も更新
  - 空のフォルダ（Textures）を作らないように
  - 服・アクセを一覧からも選べるように
- Unity 2022.3.22f1 の実機で確認して修正
  - 狭いウィンドウでヘッダーの文字と言語選択が重なる不具合を修正
  - 本文の余白が効いていなかった不具合を修正
  - 脱ぎ着: チェックを変えても通信量の表示が変わらない不具合を修正
  - 脱ぎ着: 「元に戻す」のあともチェックが前の状態のまま残る不具合を修正
  - 脱ぎ着: 小物を「L」「R.001」のような中のメッシュ名ではなく、小物の名前で表示
  - 漢字とかなでフォントの太さがばらばらに見える問題を修正（言語ごとに Windows 標準の UI フォントでそろえる）
  - やりたいことを選び直すたびに、カード一覧（②）まで作り直されて見た目が一瞬変わる問題を修正（選択中の印だけ付け替える）
  - 選択中のカードだけ枠線が太く、中の文字の折り返しが変わってカード一覧の高さがずれていた問題を修正
  - ③が短い項目に切り替えたとき、スクロール位置が巻き戻って②まで動いて見える問題を修正
