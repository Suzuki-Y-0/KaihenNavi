# 更新履歴

## 0.1.0（開発中）

- 初版。体験版の 3 機能を実装。
  - 髪や服の色を変えたい（lilToon は色調補正、それ以外はメインカラー）
  - 服やアクセを脱ぎ着できるようにしたい（Modular Avatar があればメニューを自動生成）
  - アクセの位置や大きさを直したい（矢印ボタンとスライダー）
- 操作ごとの自動バックアップと「元に戻す」「履歴」
- 日本語・英語・中国語（簡体字）・韓国語に対応
- 自分用アバター（未確認）
  - 買ったときの Prefab のまま改変しようとすると「自分用アバターを作る」を案内（1 クリックでプレハブバリアントを作ってつなぎ替え）
  - 改変を自分用アバターに自動で保存（元の Prefab には書き込まない）
  - 製品版: 自分用アバターの一覧、シーンに出す、別バージョンを作る、名前を変える
- Unity 2022.3.22f1 の実機で確認して修正
  - 狭いウィンドウでヘッダーの文字と言語選択が重なる不具合を修正
  - 本文の余白が効いていなかった不具合を修正
  - 脱ぎ着: チェックを変えても通信量の表示が変わらない不具合を修正
  - 脱ぎ着: 「元に戻す」のあともチェックが前の状態のまま残る不具合を修正
  - 脱ぎ着: 小物を「L」「R.001」のような中のメッシュ名ではなく、小物の名前で表示
  - 漢字とかなでフォントの太さがばらばらに見える問題を修正（言語ごとに Windows 標準の UI フォントでそろえる）
  - やりたいことを選び直すたびに、カード一覧（②）まで作り直されて見た目が一瞬変わる問題を修正（選択中の印だけ付け替える）
  - 選択中のカードだけ枠線が太く、中の文字の折り返しが変わってカード一覧の高さがずれていた問題を修正
  - ③が短い項目に切り替えたとき、スクロール位置が巻き戻って②まで動いて見える問題を修正
