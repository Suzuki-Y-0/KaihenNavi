あなたは Unity 2022.3 のエディタ拡張「かいへんナビ」（このリポジトリ、パッケージ Packages/com.suzuki-y0.jeni.kaihen-navi）の開発担当です。対象は VRChat 改変の初心者。日本語でコメントを書き、既存のコードスタイル（C# 7.3 相当、var、日本語 XML コメント）に合わせてください。まず HANDOFF.md と関係するコードを読んで全体を把握してください。

## 守るルール
- コードは Editor 専用。アップロードされるアバターに独自スクリプトを残さない（MA などの既存コンポーネントは可）。
- アバターや服・アクセの元アセットは書き換えない（必ず複製してから変更）。
- 新しいファイルを足したら `python3 tools/gen_meta.py` で .meta を作る。
- Unity はここでは動かせない。`bash tools/check.sh` でスタブを使ったコンパイル確認と翻訳チェックができるので、最後に必ず通すこと（スタブが足りなければ tools/stubs に最小限追加してよい）。
- 言語ファイル（Editor/Localization/*.json）に新しいキーを足すときは ja / en / zh-Hans / ko すべてに入れる。文言は初心者が読んで分かる言葉で。画面上の同じ機能の名前は、左ナビの名前（feature.ID.nav）とボタン名などでそろえる。
- UI は Editor/UI/KaihenNavi.uss の既存トークンとクラス（kn-*）を使い、今の VCC 風デザインに合わせる。Unity 標準の GenericMenu のような見た目のものを新しく足さない。
- **このツールで行う変更はすべて Ctrl+Z（Undo）で戻せること。** Undo.RegisterCreatedObjectUndo / Undo.RecordObject / Undo.AddComponent / Undo.DestroyObjectImmediate / Undo.SetTransformParent などを使い、1 つの操作は Undo.SetCurrentGroupName + CollapseUndoOperations で 1 手にまとめる。ウィンドウ側の自動保存やバックアップが Undo 履歴を壊さないか注意。
- git commit はしないこと（こちらでレビューしてコミットする）。最後に変更点と、Unity で確認が必要な点を日本語で短くまとめる。
## 担当：「アクセをつけたい」（Features/TransformFeature.cs）と「服やアクセを脱ぎ着できるようにしたい」（Features/ToggleFeature.cs）

ユーザー（作者）が Unity で触った感想：
- アクセ：アクセを選び「どこにつけますか？（頭など）」で付けると、全然関係ない位置に付いて終わり。推定はありがたいが、それは初期値にすぎない。付けたその場で位置（上下・前後・左右）・向き・大きさを簡単に調整できるところまでやってほしい。
- アクセ：付けた後すぐ外せるようにしてほしい。Ctrl+Z で戻せない。簡単に付けられるのに簡単に戻せないのはダメ。
- 脱ぎ着：メニューを作ったあと Ctrl+Z で戻せない。
- 脱ぎ着：メニューを作ったり消したりしているうちに、服（オブジェクト）が消えた（非表示になった）。初期値が勝手にオフにされたのか分からない。MA Object Toggle の初期値はオンになっていたが、メニューを消したら服が消えた。

## やること
1. 原因調査：なぜ Ctrl+Z で戻せないのか（Undo 登録漏れ、ウィンドウの自動保存/バックアップ/Rebuild が履歴を壊している、など）をコードから特定し、まとめに書く。KaihenNaviWindow の OnUndoRedo なども確認。
2. アクセを付ける操作、脱ぎ着メニューを作る/作り直す/消す操作を、すべて 1 回の Ctrl+Z で完全に戻せるようにする。
3. アクセ：「つけたアクセ」一覧をページに出し、各行に「外す」ボタン（Undo 可能に削除）と「調整」ボタン。
4. アクセ：付けた直後に、その場で調整パネルを開く：
   - 位置：上下・前後・左右のスライダー（アバターの大きさに合わせた範囲、cm 表示）、向き：3 軸の回転スライダー、大きさ：一様スケール（%）。値は付けた骨からの相対（localPosition 等）。各スライダーは Undo 可能。
   - Scene ビューでも動かせるよう、対象を Selection に入れ、SceneView.lastActiveSceneView.Frame で寄せ、Tools.current = Move にする（ボタン「シーンで動かす」）。
   - 「推定した位置に戻す」「完了」ボタン。
   - 初期位置の推定を改善する：アクセの Prefab の元の位置（ワールド原点基準でモデリングされたもの）をそのまま骨の下に入れて変な所に飛ぶ問題を避ける。付ける骨の位置にアクセの見た目の中心（Renderer の bounds の中心）が来るように置き、頭なら頭の上側、首なら首周り、などの簡単な補正を入れる。アバター用に作られたアクセ（元の位置がアバターに合っているもの）は元のワールド位置を保ったまま骨の子にする方が正しい場合があるので、Prefab 名/フォルダ名にアバター名が入っている時や、元の位置が骨の近く（体の大きさの 20% 以内など）にある時はワールド位置を保つ。判断の仕組みはまとめに書く。
   - 既存の「どれを直す？」の調整 UI があるならそれと統合し、重複させない。
5. 脱ぎ着：メニューを作る/消すときにオブジェクトの表示状態（GameObject.activeSelf）を勝手に変えない。消したときは作る前の状態に戻す（元の状態を記録しておく）。MA Object Toggle の初期値と、エディタ上の表示状態の関係を調べ、服が消えた原因をまとめに書く。
6. 脱ぎ着：作ったメニューを消す（元に戻す）ボタンがページ上で分かりやすくあること。
